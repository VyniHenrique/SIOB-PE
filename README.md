# SIOB-PE

#### Esse é um projeto que desenvolvi para o meu projeto integrador do meu 3° período, ele visa ser um gerenciador de ocorrências para o CBMPE(Corpo de Bombeiros Militares de Pernambuco). O principal objetivo do SIOB é que nele você possa fazer um CRUD de ocorrências completo de forma eficiente. Ele é composto por duas aplicações independentes, um PWA e um app mobile, e uma API que se comunica com as duas aplicações e o banco de dados.

### Pré-requisitos
- Node.js 22
- Java 21
- Maven
- PostgreSQL
- Docker (Opcional)

###  Estrutura do Projeto

Este é um monorepo que contém os seguintes módulos:

| Módulo | Tecnologia | Caminho |
| :--- | :--- | :--- |
| **Backend** | Java / Spring Boot | [`/backend`](./backend) |
| **Frontend** | React / Vite | [`/frontend`](./frontend) |
| **Mobile** | React Native / Expo | [`/mobile`](./mobile) |
